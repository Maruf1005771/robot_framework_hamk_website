# HAMK Website Automated Testing with Robot Framework

## 📌 Project Overview
This project focuses on automated UI testing of the **HAMK (Häme University of Applied Sciences)** website using **Robot Framework** and **SeleniumLibrary**. The goal is to validate key website functionalities such as navigation, dynamic content loading, search features, lecturer information, news articles, language switching, study options, and multimedia content 🎥.  
Since the HAMK website loads content dynamically, explicit waits and `Sleep` keywords are used to ensure reliable test execution.

🌐 Website under test: https://www.hamk.fi/en/
